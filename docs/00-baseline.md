### 1-2. AI 컴패니언 프로토타입 (v0.1.x, 2026-05-12) [F, 로컬 코드]

- 위치: `riot-esports-ontology/ai-companion/extension` (MV3, 별도 매니페스트 "RORR AI Companion")
- 완료: VRM 3D 렌더링, Mixamo 애니메이션, 감정 9종·카메라 연출·배경 이펙트, Claude Haiku 대화, IndexedDB 관계 기억, 립싱크, 아이들 모드
- 미구현: 아이들 하트비트(45초 자동 발화), 관계 레벨, 기억 → 대화 컨텍스트 주입, **경기 데이터 폴링·이벤트 감지**, 사운드
- 구조적 한계
  - **사용자 본인의 Anthropic API Key를 로컬에 저장**하는 테스트 구조 → 공개 배포 불가
  - 경기 데이터 미연결 → "경기를 같이 보는" 핵심 가치가 아직 작동하지 않음
  - 게시본(1-1)과 **별개 확장** — 통합 경로 미정

### 1-3. 웹 rorr.club (rorr-hero, 2026-10-15 기준) [F, 저장소]

- 팬 전용 담백한 홈 + 블로그. Ask(드라이한 인사이트 Q&A), Boost(Energy/Spark), 모먼트 카드, 서포터 순위, LwRC+ 표, Muse 큰 순간 알림(사이트 열린 동안만)
- 확장 관련 현행 문안: 블로그 "Meet Muse, and why she lives next to the stream" — **혜택은 웹과 동일, 차이는 시청 경험 4가지**
  1. 중계 옆 사이드 패널 / 2. 탭 전환 없는 순간 Boost / 3. 시청 중 큰 순간 예고 / 4. 질문에 라이브 맥락 자동 첨부
- 웹 내 "Watch with Muse for 30 seconds" 사이드 패널 미리보기 모형 존재 → 설치 CTA = 웹스토어 링크(현 게시본)
- Next.js 포팅 진행 중, 기준 저장소는 rorr-hero 유지
