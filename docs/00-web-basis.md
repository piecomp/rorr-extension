## 2. 웹 미리보기("Watch with Muse for 30 seconds") = 익스텐션 사양서

- 웹 `#muse` 모달은 샘플 리플레이로 익스텐션 체험을 연출한다. 아래 요소는 **실제 익스텐션이 동일하게 구현해야 할 약속**으로 간주

| 미리보기 요소 | 연출 내용 | 익스텐션 기능 |
|---|---|---|
| 첫 인사 | "Hi! I'm Muse. I watch matches right beside the stream." | 첫 실행 온보딩 (F-01) |
| 응원 팀 칩 | "Who are you cheering for today?" → 팀 칩 선택, **로그인 없이** | 응원 팀 선택 → 팀 모드 진입 (F-07) |
| 미니 스코어 | 팀·킬 스코어·게임 시각·골드 바(EVEN/+n)·맵 오브젝트(드래곤·바론) | 라이브 매치 스트립 (F-03) |
| 이벤트 플래시 | "DRAGON — T1", "BARON STOLEN — T1" 라벨 | 순간 플래시 (F-04) |
| Muse 감정 | calm / happy / sad / tense / hype 5단계 + 팀 컬러 파티클 | Muse 감정 반응 (F-02) |
| 대사 톤 | "Dragon's ours!!", "Ugh… that one hurt. It's okay, it's not over.", "Wait, wait… they're on Baron." | 팀 모드 말투 (말투 가이드) |
| 빠른 반응 버튼 | Cheer! / Ugh… / LET'S GO | 무료 빠른 반응 (F-05) |
| 하단 문구 | "She never reads numbers at you." | 원칙: 수치 낭독 금지 |
| 마무리 | 다음 경기 일시 안내 + "Want me to call you when it starts?" | 다음 경기 알림 옵트인 (F-09) |
| CTA | "Bring Muse to T1's next match · Free" | 설치 후 첫 경기 연결 |
| 표기 | "Sample replay · not a real match" | 실제 제품은 라이브 매칭 상태 표시 |

- 함의: 웹 미리보기는 **킬 스코어·골드 바를 보여주되 Muse가 숫자를 말하지 않는다** → 수치는 스트립(시각), 감정은 Muse(말)로 역할 분리

## 5. 웹과 익스텐션이 같은 서버를 쓴다 (전제)

- 웹 Next.js 포팅 시 정의되는 DB·API(서비스 플로우 v2)를 익스텐션도 그대로 사용 — **익스텐션 전용 엔드포인트는 최소화**
- 익스텐션 추가 요구 API는 3종으로 한정 [제안]
  1. 중계 URL → 경기 매칭
  2. 실시간 순간 스트림(SSE/WebSocket) — 웹 Muse 알림도 같은 스트림 사용 권고
  3. 세그먼트 캐시 Muse 대사
- 포팅 핸드오프(`rorr-hero/docs/HANDOFF.md`)의 변경 이력 표에 익스텐션 영향 열 추가 요청 [제안] — 웹 변경이 익스텐션에 전파되는 경로 확보
