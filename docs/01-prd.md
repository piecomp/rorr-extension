- 작성일: 2026-10-15 · 상태: 초안 v0.2 (웹 기획 기반 재작성) · 오너: Jun(CPO) [제안]

## 1. 정의

- **웹(rorr.club) = 찾아보는 곳, 익스텐션 = 보는 곳**
- 익스텐션은 웹의 **라이브 시청용 선택 클라이언트**. 같은 계정·재화·카드·응원 포인트를 쓴다
- **웹과의 차이 3가지 [확정 2026-10-15]**
  1. **Muse가 메인** — 웹은 인사이트 Q&A가 메인, 익스텐션은 Muse가 화면의 주인공
  2. **경기 이벤트 퀴즈 스트릭** — 경기 중 Muse가 다음 이벤트를 묻고, 연속 정답이 이어진다
  3. **퀴즈 순위와 Spark 상금** — 스트릭 결과로 참여자 순위, 상위자에게 Spark 지급
- 팬 언어: "Muse는 크롬에서 경기 옆에 앉아 있어요. 큰 순간이 오면 먼저 말을 걸고, 같이 응원해요"

## 2. 문제 (웹이 혼자 풀 수 없는 것)

- **경기는 다른 탭에서 일어난다** — 웹은 큰 순간마다 중계를 떠나 RORR 탭으로 오라고 요구한다 [웹 블로그]
- **웹의 Muse 알림은 RORR 탭이 열려 있을 때만 닿는다** [정책 §5-4] — 시청 중인 팬에게는 닿지 않는다
- **웹 Ask는 지금 보는 경기·초를 모른다** — "방금 그거"를 물을 수 없다
- **영문권 팬은 혼자 본다** — LCK는 북미 새벽·유럽 업무시간 [F 시차 / H 크기]

## 3. 목표 / 비목표

- 보류 [확정 2026-10-15]: 웹스토어 리스팅·등록 정보 수정 — 후속 단계

## 4. 타깃

1. 영문권 LCK 라이브 시청 매니아 (Twitch·YouTube) — 그중 **T1 팬덤** (유일한 파트너 팀)
2. 국내 오가닉(치지직·SOOP) — 막지 않되 모수 미반영, 플랫폼별 분리 계측

## 5. 제품 원칙

1. **웹과 같은 말, 같은 규칙** — 문구·재화·카드·포인트 규칙은 웹과 정책 사본에서 가져온다. 익스텐션이 새 규칙을 만들지 않는다
2. **미리보기의 약속을 지킨다** — 웹 `#muse`에서 보여준 것은 전부 실제로 한다
3. **Muse는 숫자를 읽어주지 않는다** — 수치는 스트립과 펼침 2층, 말은 감정
4. **플레이를 말하고 사람을 판정하지 않는다**
5. **중계를 건드리지 않는다** — 사이드 패널 안에서만
6. **순간을 끊지 않는다** — 경기 중 순간 영역에 결제·광고·업셀 금지
7. **관리·탐색은 웹으로 보낸다** — 순위·통계·충전·결제 내역·블로그는 링크
