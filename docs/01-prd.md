## 1. 제품 정의

- **한 줄 정의**: LCK 중계를 보는 팬 옆(크롬 사이드 패널)에 서하(Muse)가 앉아, 큰 순간을 먼저 알려 주고 그 순간에 함께 응원(Boost)하게 하는 시청 동반자. 웹 rorr.club과 같은 계정·재화·카드·EXP를 사용
- **비전(2026-10-20)**: RORR와 함께라면 LCK를 **더 오래, 더 넓게** 본다 — 경기 전·중·후를 잇고, 응원 팀 경기에서 리그 전체로 넓힌다
- 역할 구분: 웹 = 찾아보는 곳 / **확장 = 보는 곳**. 확장은 웹의 라이브 시청용 선택 클라이언트
- 웹과의 차이(확장 전용)
  1. **서하가 메인** — 감정 반응·먼저 말 걸기·1:1 대화
  2. **경기 이벤트 퀴즈 스트릭** — 퀴즈 EXP, 게임·매치 결과, 주간 Spark 상금
  3. **서하 친밀도** — 함께 본 시간의 관계 기록(재화·순위 무관)
- 팬 언어: "서하는 크롬에서 경기 옆에 앉아 있어요. 큰 순간이 오면 먼저 말을 걸고, 같이 응원해요"

## 2. 문제

| 문제 | 내용 |
|---|---|
| 경기는 다른 탭에서 일어난다 | 웹은 큰 순간마다 중계를 떠나 RORR 탭으로 오라고 요구함 |
| 웹 알림은 시청 중인 팬에게 닿지 않는다 | 웹의 큰 순간 알림은 RORR 탭이 열려 있을 때만 표시(정책 §5-4) |
| 웹 질문은 지금 보는 장면을 모른다 | "방금 그거"를 물을 수 없음 |
| 영문권 팬은 혼자 본다 | LCK는 북미 새벽·유럽 업무시간 — 함께 보는 경험이 없음 |
| 시청이 경기 단위로 끊긴다 | 경기 전 진입·경기 후 다음 경기 연결 장치가 없음 |

## 4. 사용자

### 4-1. 타깃

| 구분 | 대상 | 비고 |
|---|---|---|
| 1차 | **영문권 LCK 라이브 시청 매니아(Twitch·YouTube), 그중 T1 팬덤** | 마케팅 대상, 클로즈드 베타 테스터 |
| 2차 | 국내 오가닉(치지직·SOOP) | 막지 않되 모수 미반영, 플랫폼별 분리 계측 |
| 기존 사용자 | 스토어 게시본 v1.1.2 사용자 | 같은 스토어 항목 업데이트로 승계 |

### 4-2. 핵심 시나리오

1. **첫 실행**: 웹 미리보기 완주 → 설치 → 패널 열기 → 응원 팀 선택 → 중계 탭 감지·경기 매칭(실패 시 경기 선택)
2. **경기 중 동반 시청**: 서하가 경기 시작 때 "내 선수"를 한 번 묻고 → 퀴즈 출제 → 골드 순간 예고 → Boost 시트(수량 20 이상이면 메시지 입력·등급 미리보기) → 두 번 누르기 → 카드 공개 → 응원 EXP. 스코어 아래에는 최근 고정 응원 한 줄(+N)이 보이고, 누르면 모먼트 패널에서 해당 메시지가 펼쳐짐
3. **게임 종료**: 게임이 끝나면 "이번 게임 상위 N%" 1회 표시 → 경기 종료 시 결과 카드(상위 %·최장 스트릭) 공유 → 다음 경기 시작 알림 옵트인
4. **평시**: 경기가 없을 때 서하와 대화(추천 질문 무료, 직접 대화는 로그인 + 주간 무료 횟수 이후 Spark/Energy 선택 차감)
5. **Energy 부족**: 토스트 + 웹 충전 링크 → 복귀 시 잔액 재조회

## 5. 제품 원칙

1. **웹과 같은 말, 같은 규칙** — 규칙은 정책 사본에서 가져온다. 확장이 새 규칙을 만들지 않는다
2. **미리보기의 약속을 지킨다** — 웹 `#muse`에서 보여 준 것은 전부 실제로 한다
3. **서하는 숫자를 읽어 주지 않는다** — 수치는 스트립과 펼침, 말은 감정
4. **플레이를 말하고 사람을 판정하지 않는다** — 선수 실수·데스 평가·퀴즈 금지
5. **중계를 건드리지 않는다** — 사이드 패널 안에서만, 시청 상태 판별은 로컬
6. **순간을 끊지 않는다** — 경기 중 순간 영역에 결제·광고·업셀 금지. 고정 응원은 메인 화면 스코어 아래 **한 줄**(최근 1건 + N, 자동 넘김 없음)만 허용하고 큰 순간 예고·퀴즈·Boost 화면 중에는 숨김(정책 §5-1, 2026-11-03 개정)
7. **스포일러 0** — 결과형 이벤트는 개인 지연 도달 후, 다시보기 상태에서는 결과형 알림 끔
8. **Pay to win 없음** — EXP·순위는 결제 금액과 무관(정책 v1.5)
9. **관리·탐색은 웹으로** — 충전·환불·광고 월·알림함·전체 순위는 링크

| 참여 | 퀴즈 참여율·평균 스트릭 | 경기당 1문항 이상 응답 비율 | M3 |
| 참여 | 무료 참여 비율 | Spark Boost 비율, 응원 메시지 등급 분포 | 4주 후 등급표 재검토 |
| 유지 | 다음 경기 복귀율 | 경기 시작 알림 옵트인자 중 다음 경기 패널 오픈 | M3 |
| 전환 | 미리보기 → 설치 → 첫 매칭 | 웹 `#muse` 완주 → 설치 → 7일 내 매칭 | M3 |
| 품질 | 스포일러 신고 0, Boost 성공률 99.5%, 원장 불일치 0 | `handoff/13` §5 | **M4 출시 조건** |

- 효과 측정: 3층 기준선 — L1 같은 사람의 패널 열림/닫힘 시청 비교, **L2 기능별 무작위 대조군(주 지표)**, L3 리그 공개 시청 추세·설문. 내부 주간 대시보드 + 파트너 월간 리포트
- 가드레일: 알림 피로, 스포일러, Boost 참여율 하락 없음 — 시청 시간을 위해 알림을 늘리지 않음. **고정 응원 한 줄 끄기 비율·시청 방해 응답**(베타 설문) 추적
- 금지: 총 MAU 단독 보고, LTV/CAC 노출
