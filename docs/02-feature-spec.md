## F-01 중계 감지·경기 매칭 (P0)

- 목적: 사용자가 지금 보는 중계가 어느 경기인지 확정 → 모든 실시간 기능의 전제
- 요구사항
  - 지원 호스트 4곳: YouTube, Twitch, 치지직, SOOP — **URL·탭 제목만 읽는다**(DOM 변경 없음)
  - 진행 중 경기 목록과 대조해 자동 매칭, 실패 시 "지금 보는 경기 선택" 수동 선택
  - LCK 외 리그 중계 감지 시: 리그 칩 비활성 + "Soon · 알림 받기"
  - **중계 지연 보정**: 플랫폼별 기본 오프셋 + 사용자 1회 미세 조정("방금 바론 처치 화면이 나왔나요?" 탭 1번)
- AC
  - 지원 호스트의 LCK 공식 채널에서 패널 오픈 후 3초 내 매칭 또는 수동 선택 제시
  - 매칭된 경기의 큰 순간이 **중계 화면보다 먼저 스포일러 되지 않는다**(보정 후 지연 기준)
- 비고: 스포일러 방지는 품질 1순위 — 데이터 피드가 중계보다 빠를 때 예고는 허용, 결과 발화는 보정 시간까지 보류

## F-02 Muse 패널 (P0)

- 목적: "함께 보는 존재" — 감정 반응이 1층
- 요구사항
  - 캐릭터 렌더러: `CompanionRenderer` 추상화 유지, 출시 렌더러는 OI-10 결정(Live2D 스타일 vs VRM 3D)
  - 감정 상태 9종·카메라·이펙트(프로토타입 계승). 경기 이벤트 → 감정 트리거 4유형(빅 이벤트/마이크로/아이들 하트비트/채팅)
  - **팀 모드**: 응원 팀 선택 시 관찰자 → 같은 편. 인칭 "we", 감정 고조, 설명은 감정이 지나간 뒤
  - 말투: 영어 기본, 한국어 로컬라이제이션(번역 아닌 별도 작성). 대명사 she
  - 발화 빈도 상한: 아이들 하트비트 기본 45초, 경기 중 큰 순간 직후에는 침묵 구간 확보 [제안]
- AC
  - 말투 가이드 §2 금지 표현(사람 판정·상대 비하) 0건 — 출시 전 레드팀 문장 세트 통과
  - 미계약 팀 경기: 선수 닉네임·팀 별칭·응원구호 미사용 (정책 §2)

## F-03 큰 순간 예고 (P0)

- 목적: 순간이 열리기 전 몇 초의 창을 팬에게 넘긴다 — 확장의 대표 가치
- 요구사항
  - 등급: **골드**(승부처) / **홀로그램**(결승·역대급) — 모먼트 카드 테두리와 동일 기준
  - MVP 트리거(카탈로그 subset) [제안]: B1 바론/장로 각, C1 승률 급변(±15%p), A3 넘버스 어드밴티지. 예측형은 확률·근거 1줄 병기
  - 표시: 골드 = 패널 상단 배너(Muse 반신 + 순간명 + 카운트다운) / 홀로그램 = 패널 중앙 연출. **패널 밖(중계 탭) 오버레이 없음**
  - 패널이 닫혀 있을 때: 확장 아이콘 배지(점·숫자)만 [제안]. 시스템 알림(chrome.notifications)은 기본 OFF, 사용자 옵트인 시 홀로그램만 (OI-08)
  - 빈도 상한: 배너 3분 1회, 홀로그램 경기당 1회, 결제·Boost 완료 모달 위 금지 (정책 §5-4 준용)
  - 설정: 골드+홀로그램 / 홀로그램만 / 끄기
  - CTA "이 순간 Boost 준비" — **자동 차감 없음**
- AC: 예고가 무산되면 배너를 조용히 거둔다(실패 문구로 주의 끌지 않음), 무산률 계측

## F-04 순간 Boost (P0)

- 목적: 탭 전환 없이 한 번에 응원
- 요구사항
  - Energy ⚡ / Spark ✦ **잔액·아이콘·색 분리 표시**, 합산 금지. 버튼에 차감 재화 명시
  - 기능 매트릭스는 정책 §2 그대로: 파트너(T1) 경기 = Energy·Spark / 미계약 팀 경기 = Spark만 + 필수 고지 문구
  - Boost 확인 화면에 "사용 즉시 제공 완료, 취소 불가" 고지 (정책 §1-1)
  - 파트너 경기: "일부가 팀에 전달" 1줄 + ⓘ 펼침에서 비율(팀 70 : RORR 30)·정산 기준
  - 같은 순간 재Boost: 재화는 차감, 포인트·카드는 1회만 (정책 §5-3)
  - 양팀 모두 응원 팀인 경기: 응원 대상 팀 명시, 적립은 순간을 만든 팀 (정책 §5-2)
  - **Energy 충전은 웹(rorr.club) 결제 화면으로 위임** [제안] — 확장 내 결제 UI 미보유 (OI-12)
  - Spark 획득(광고 월)은 웹 전용 — 확장에서는 "웹에서 Spark 받기" 링크만
- AC: 미계약 팀 경기에서 Energy 버튼 비노출, "팀에 분배되지 않음" 표기

## F-05 모먼트 카드 (P0)

- 요구사항: 정책 §4 그대로 — 경기 중 순간 Boost 시 즉시 1장, 무작위 없음, 거래·판매 불가, 등급=순간 크기, 장식=Boost 양
  - 비파트너 경기 = RORR 모먼트 카드(엠블럼 + 승리확률 스윙 그래픽), 파트너 = 파트너 에디션(협약 확정 전 "논의 중")
  - 카드 노출 화면에 "판매하지 않음 · 경기 중 Boost 시 웹·확장 어디서든 획득" + 안내 글 링크
  - 공유 이미지: 날짜·기준·출처·비제휴 고지 포함, 팀 1개 단위
- AC: 웹에서 받은 카드와 확장에서 받은 카드가 같은 컬렉션에 동일 형식으로 표시

## F-06 Ask — 라이브 맥락 질문 (P1)

- 요구사항
  - 질문에 경기 ID·세트·현재 게임 시각을 **자동 첨부** ("방금 그 교전 왜 졌어?"가 성립)
  - 과금 원칙은 웹과 동일: 추천 질문(서버 캐시 답변) 무료 / 직접 입력은 로그인 필수 [확정 2026-10-06]
  - 답변 톤: 웹 Ask는 드라이한 인사이트, 확장의 Muse 대화는 감정 1층 + 근거 링크 2층
- AC: 근거가 있는 수치는 타임스탬프 링크 동반, 근거 없는 수치 생성 0건

## F-07 계정·응원 팀 (P0)

- 요구사항
  - rorr.club 단일 계정 로그인(웹 세션 연동) — 비로그인도 Muse 반응·예고 시청 가능, Boost·Ask 입력은 로그인 필요
  - 응원 팀 복수 선택 + **대표 팀** 1개 (정책 §5-2). 팀 변경은 가능하되 눈에 띄게 만들지 않는다(말투 가이드 §1)
  - 미성년자: 만 14세 미만 법정대리인 동의 흐름, 미성년 결제 한도·노출 기본 OFF (정책 §7) — 웹 흐름 재사용
- AC: 웹에서 바꾼 응원 팀·잔액이 확장에 30초 내 반영

## F-08 인사이트 카드 (P1)

- 요구사항: 펼쳐야 보이는 2층. LwRC+ 실시간(잠정치 표기), 승리확률 그래프, 순간 근거 링크
  - 팬 수준 2단: 입문 = 승부처 이해 / 매니아 = 드래프트·쿨다운·골드
  - "LwRC+ — 야구의 wRC+처럼 100이 리그 평균" 설명 허용, "LoL wRC+" 표기 금지 (정책 §3)
- AC: Live 수치는 "잠정", 경기 종료 후 정본으로 교체 표시

## F-09 고지·설정 (P0)

- 개인정보 처리방침·문의처(privacy@rorr.club / support@rorr.club) 링크

## F-10 관계 기억 (P1)

- 프로토타입 IndexedDB 에피소드 기억 계승. 강도 high 순간(예: 함께 본 역전) 자동 저장 → 다음 경기 첫 인사에 1회 회상
- 기본 **로컬 저장**, 서버 동기화는 동의 설계 후 (OI-11)
- 관계 레벨·친밀도 포인트는 **응원 포인트·순위와 분리** — 과금·순위에 영향 없음 [제안]
