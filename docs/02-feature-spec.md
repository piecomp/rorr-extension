## P0

### F-01 첫 실행 온보딩

- [웹] 미리보기 순서 그대로: 인사 → "Who are you cheering for today?" → 팀 칩 → 팀 모드 진입 대사
- 로그인 없이 진행. 로그인은 첫 Boost·직접 질문 시점에 요청 (가치 체험 후 로그인)
- 툴바 고정 안내 1회, 중계 탭으로 이동 안내 1회
- AC: 설치 → 팀 선택까지 탭 3회 이내, 로그인 요구 0회

### F-02 Muse 감정 반응

- 렌더러 = **VRM 3D [확정 2026-10-15]** (three-vrm, 프로토타입 계승). `CompanionRenderer` 인터페이스는 유지
- 감정 5단계 **[웹] calm / happy / sad / tense / hype** — 프로토타입 9종 감정은 내부 세분화로 매핑
- 트리거: 오브젝트·한타·바론/장로 시도·스틸·진격·세트 종료 (미리보기 이벤트 세트가 MVP 최소 범위)
- 팀 모드 말투: "we", 상대 비하 금지, 플레이를 말하고 사람을 판정하지 않음 (말투 가이드 §2)
- **[웹] "She never reads numbers at you."** — 대사에 수치 없음. 수치는 F-03 스트립이 담당
- 팀 컬러 파티클: 응원 팀 색(좌 #2F9CFC / 우 #FE2054). 미계약 팀 경기는 팀 고유 색 대신 좌/우 중립 색 [정책 §2]
- AC: 레드팀 문장 세트(선수 판정·상대 비하·수치 낭독) 위반 0건

### F-03 라이브 매치 스트립

- [웹] 미리보기 상단 구성: 팀명·킬 스코어·게임 시각·골드 바(EVEN / 팀 +n)·맵 오브젝트(드래곤·바론 상태)
- 세트 표시: [웹] 경기 페이지 표기("Game 2 · live")
- 미계약 팀 경기: 팀명은 경기 식별 1회(가능하면 "오늘의 1경기"), 로고·색 없음 [정책 §2]
- 중계 지연 보정 적용 후 표시 (스포일러 방지, `04` §4)
- AC: 스트립 갱신 지연 ≤ 보정 기준 + 2초

### F-04 큰 순간 예고·순간 플래시

- 예고 [웹 §5-4 승계]: 골드 = 상단 배너(Muse 반신 + 순간명 + 카운트다운) / 홀로그램 = 패널 중앙 연출
- 순간 플래시 [웹 미리보기]: "DRAGON — T1", "BARON STOLEN — T1" 형식 라벨
- 빈도 상한 [웹]: 배너 3분 1회, 홀로그램 경기당 1회, 결제·Boost 완료·로그인 모달 위 금지
- 설정 [웹]: 골드+홀로그램 / 홀로그램만 / 끄기 — 웹 "내 Boost > 공개 설정"과 같은 값 동기화
- 패널 닫힘 시: 확장 아이콘 배지 (웹의 "탭 제목 앞 (⚡ 곧 바론) + 파비콘 점"에 대응)
- CTA "이 순간 Boost 준비" — 자동 차감 없음 [웹]
- AC: 무산된 예고는 조용히 철회, 무산률 계측

### F-05 빠른 반응 (무료)

- [웹 미리보기] Cheer! / Ugh… / LET'S GO 3버튼 — 재화 소모 없음, 로그인 불필요
- Muse가 사용자 반응에 짧게 맞장구 (말풍선 갱신, 연속 입력 시 쿨다운)
- 응원 포인트·순위 **미반영** [제안] — 정책 §5-3 포인트는 Boost 기준 유지, 어뷰징 차단
- 집계는 경기 순간별 익명 합계로만 활용 (예: "지금 1,240명이 LET'S GO") [제안, 정책 검토 필요 OI-18]

### F-06 순간 Boost

- [웹·정책] Energy ⚡ / Spark ✦ 분리 표시·합산 금지, 버튼에 차감 재화 명시, 최소 단가 웹과 동일(⚡10+)
- 파트너(T1) 경기 = Energy·Spark / 미계약 팀 경기 = Spark만 + 필수 고지 [정책 §2]
- [웹] Boost 시트 상단 "Boosting together right now: n"
- [웹] 배분 표시: "일부가 팀에 전달" 1줄 + ⓘ 펼침(팀 70 : RORR 30)
- 확인 단계 "사용 즉시 제공 완료, 취소 불가" 고지 [정책 §1-1]
- 응원 메시지 동시 작성(선택) — 욕설 필터 [정책 §5]
- 충전·Spark 획득은 웹 위임: "웹에서 충전" / "웹에서 Spark 받기"
- AC: 같은 순간 재Boost 시 포인트·카드 중복 없음 [정책 §5-3]

### F-07 계정·응원 팀

- 웹 계정 그대로 (Google·Apple·Microsoft·이메일), 웹 인증 화면 경유 로그인
- 응원 팀 = 웹 즐겨찾기 팀과 동일 데이터. 복수 응원 팀 + 대표 팀 [정책 §5-2]
- 비로그인 상태 팀 선택은 로컬 저장 → 로그인 시 계정 즐겨찾기로 병합
- 미성년자 흐름은 웹 화면 재사용 [정책 §7]
- AC: 웹에서 바꾼 응원 팀·잔액이 30초 내 반영

### F-08 모먼트 카드

- **카드 규칙은 정책 v1.2 그대로 유지 [확정 2026-10-15]** — 익스텐션에서 별도 규칙 추가 없음
- [웹·정책 §4] 경기 중 순간 Boost 시 1장, 무작위 없음, 판매·거래 없음, 등급 = 순간 크기, 장식 = Boost 양
- 발급 연출 = 웹 Boost 완료 모달과 같은 틀(Muse 중심)
- 카드 노출 화면에 [웹] "판매하지 않음 · 경기 중 Boost 시 웹·확장 어디서든 획득" + 안내 글 링크
- 비파트너 경기 = RORR 모먼트 카드(엠블럼 + 승리확률 스윙) [웹 39dbad1]
- 자랑하기(공유 이미지)는 웹으로 위임 [제안]
- AC: 웹·확장 발급 카드가 동일 컬렉션·동일 렌더링

### F-09 관심 팀 경기 시작 알림

- 대상: **응원(즐겨찾기) 팀 경기만** — 전체 경기 알림 없음 [확정 2026-10-15]
- 구분: 경기 **시작 전** 알림만 푸시 허용. 경기 **중** 큰 순간 알림은 푸시하지 않음(정책 §5-4 유지)
- 옵트인: [웹 미리보기] "{팀} plays {날짜} at {시각}. Want me to call you when it starts?" 수락 = 동의
- 채널 우선순위 [제안, OI-22]
  1. **확장 알림**(`chrome.notifications`) — 설치자 기본. 매니페스트 선언으로 브라우저 권한 팝업 없음, RORR 탭이 닫혀 있어도 크롬 실행 중이면 도달
  2. **웹 푸시** — 익스텐션 미설치 웹 사용자용 옵트인. 권한 요청은 팀 선택 직후 맥락에서만
  3. **캘린더 구독(.ics, 팀별)** — 권한 불필요, 휴대폰 캘린더 알림으로 새벽 경기에도 도달
  4. 모바일 앱 푸시 — 앱 보유 전까지 보류
- 시점 [제안]: 시작 10분 전 1회(+ 선택 시 시작 시 1회), 같은 팀 하루 최대 2회
- 설정: 팀별 on/off, 웹 "Pause notifications for 30 days"와 연동
- AC: 응원 팀 외 경기 알림 0건 · 옵트인 없는 알림 0건 · 채널 간 중복 발송 0건(한 사용자에게 한 채널만)
