### F-20 이벤트 퀴즈 스트릭 (익스텐션 전용 · 핵심) [확정 2026-10-15]

- 정의: 경기 중 Muse가 **곧 일어날 경기 이벤트**를 2지선다로 묻고, 연속 정답이 스트릭으로 이어진다
- 문항 유형 [제안] — 라이브 푸시 트리거 카탈로그의 "윈도우" 순간에서 출제
  - 오브젝트: "다음 드래곤, 어느 팀이 가져갈까?" / "이 바론 시도, 성공할까?"
  - 교전: "다음 킬은 어느 팀?" / "이 한타, 이길까?"
  - 국면: "15분 골드 우위 팀은?" / "이 세트 첫 포탑은?"
  - 금지: 선수 개인의 실수·데스를 맞히게 하는 문항(예: "누가 먼저 죽을까?") — 말투 가이드 §2·D3 위반
- 진행
  - Muse가 말풍선으로 출제 → 퀴즈 카드(2버튼 + 마감 카운트다운) → 결과 시 Muse 감정 반응
  - 동시 진행 1문항, 문항 간 최소 간격 3분 [제안], 세트당 최대 6문항 [제안]
  - 큰 순간 예고(F-04)와 겹치면 퀴즈 카드가 먼저 마감 — Boost CTA와 화면 경쟁 금지
- 스트릭 규칙 [제안]
  - 정답 +1, 오답 시 0으로 초기화, 미응답은 유지(벌점 없음)
  - 스트릭은 **경기를 넘어 이어진다** (시즌 단위 최장 스트릭 기록)
  - 정답 점수 = 기본 10 + 현재 스트릭 × 5 (상한 적용) — 퀴즈 포인트는 **응원 포인트(정책 §5-3)와 별도 집계**
- 공정성 (필수)
  - 정답 판정·마감은 **서버 시각 기준**. 마감 = 이벤트 발생 예상 시각 − (지원 플랫폼 최대 지연 + 여유)
  - 이벤트가 마감 전에 발생하면 해당 문항 무효(전원 미응답 처리)
  - 지연이 짧은 중계·데이터 사이트를 보는 사용자 우위를 막기 위해, **결과가 어느 중계에도 아직 안 보이는 시점에 마감**
  - 응답 시각 이상치 탐지(마감 직전 대량 정답 계정), 다계정 차단
- 참여 조건: **무료, 재화 소모 없음** (Energy·Spark를 걸지 않는다 — 사행성 회피 핵심). 비로그인도 응답 가능, 순위·상금은 로그인 필요
- 미계약 팀 경기: 문항에 팀명은 경기 식별 수준만, 로고·색·선수 닉네임 없음 [정책 §2]
- AC: 결과가 공개된 뒤 응답 가능 문항 0건 · 선수 판정형 문항 0건 · 재화 차감 0건
