## 3. 핵심 플로우

### 3-1. 설치 → 첫 경기 (활성화)

1. 웹 "Watch with Muse 30초" 또는 스토어에서 설치
2. 패널 자동 오픈 안내(툴바 고정 유도 1회)
3. S0: 응원 팀 선택 → 팀 모드 진입 연출
4. 중계 탭으로 이동 → S2 자동 매칭
5. 지연 보정 1탭 ("화면에 이 장면이 나왔을 때 눌러주세요")
6. 첫 큰 순간 예고 → Boost 시도 → **이때 로그인 요청**(가치 체험 후 로그인)

### 3-2. 큰 순간 → Boost → 카드

1. 예고 배너(골드) + 카운트다운
2. "이 순간 Boost 준비" → Boost 시트(재화 선택, 파트너 여부에 따라 버튼 구성)
3. 확인(취소 불가 고지) → 순간 발생 시 확정
4. 카드 획득 연출(Muse 중심, Boost 완료 연출과 동일 틀) → Cards 탭 적재
5. 순간이 무산되면: Boost 미확정 상태 해제, 재화 미차감 [제안 — 확정 시점은 OI-13]

### 3-3. Energy 부족

- "웹에서 충전" → rorr.club 충전 화면 새 탭 → 복귀 시 잔액 갱신
- 경기 중 순간 영역에서는 충전 유도 모달 금지, Boost 시트 안 1줄 링크만

### 3-4. 미계약 팀 경기

- 팀명은 경기 식별 문장 1회(가능하면 "오늘의 1경기"), 로고·색·닉네임 없음
- Boost 시트: Spark만 + 필수 고지 문구 상시
- 카드: RORR 모먼트 카드 디자인

## 4. 문구 원칙 (패널)

- 말풍선 1~2문장, 숫자 없이 장면 중심 — "Baron's up and they're missing two summoners. This could be it."
- 근거 수치는 "이 순간 자세히" 안에서만
- 설치·로그인 CTA는 팬 언어: "Muse 데려오기", "Bring Muse to T1's next match"
- 금지: 기부·후원금·"팀을 돕는다"(미계약 팀), "공식"(협약 허용 전), "레어 카드"
