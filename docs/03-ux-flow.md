1. Muse 출제 대사 ("Dragon's up in a minute. Who takes it?") → 퀴즈 카드 등장
2. 응답 → Muse 짧은 맞장구 (정답 공개 전에는 편들지 않음)
3. 마감 → 이벤트 발생 → 결과: 정답이면 스트릭 +1 연출, 오답이면 Muse 위로 대사 + 스트릭 초기화
4. 무효(마감 전 발생) → "This one happened too fast. It won't count."
5. 주간 마감 후 상위자: 다음 접속 시 Muse가 순위·Spark 지급을 알림 (푸시 아님)
- Me 탭: 내 포인트·내 순위 1줄·최근 카드 3장·응원 팀 → "웹에서 전체 보기"

## 3. 핵심 흐름

### 3-1. 웹 미리보기 → 설치 → 첫 경기

1. 웹 `#muse` 30초 체험에서 팀 선택 → CTA "Bring Muse to T1's next match · Free"
2. 설치 → 패널 S0. **웹에서 고른 팀이 있으면 이어받는다** [제안: 설치 직후 rorr.club 쿠키/로그인 세션으로 조회, OI-19]
3. 다음 경기 안내 + F-09 옵트인 ("시작하면 제가 먼저 불러 드릴까요?")
4. 경기 시작 알림 → 중계 탭 → S2 매칭·보정 → S3

### 3-2. 큰 순간 → Boost → 카드 (웹과 동일 연출)

1. 골드 배너(카운트다운) → "이 순간 Boost 준비"
2. Boost 시트: 동시 응원 수 · 재화 선택 · (파트너) 배분 1줄+ⓘ · 메시지(선택) · 취소 불가 고지
3. 로그인 안 됨 → 웹 인증 → 복귀 시 시트 유지
4. 순간 확정 → 플래시 "BARON STOLEN — T1" → Muse hype → 카드 발급 연출 → Cards 탭 적재

### 3-3. 재화 부족

- Energy 부족: 시트 안 1줄 "웹에서 충전" → 새 탭 웹 충전 화면(⚡10~500) → 복귀 시 잔액 갱신
- Spark 부족: "웹에서 Spark 받기" — **경기 중에는 링크만, 광고 시청 유도 문구 금지** [정책 §6]

### 3-4. 미계약 팀 경기

- 스트립 팀명은 식별 1회·중립 색, Boost는 Spark만 + 필수 고지, 카드 = RORR 모먼트 카드
- Muse 대사에 선수 닉네임·팀 별칭 미사용

## 4. 문구 원칙

- 웹 확정 문구를 i18n 키로 재사용 (예: "Boosting together right now", "Sample replay" 대응 "Live · synced")
- 말풍선 1~2문장, 수치 없음
- 금지: 기부·후원금·"팀을 돕는다"(미계약 팀), "공식"(협약 허용 전), "레어 카드", 수치 낭독
