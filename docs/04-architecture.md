## 5. LLM·원가 구조

| 층 | 방식 | 원가 성격 |
|---|---|---|
| 마이크로 반응(감탄·표정) | 온디바이스 모델(Gemini Nano, 가용 시) 또는 규칙 기반 대사 풀 | ≈ 0 |
| 순간 대사(예고·리액션) | **세그먼트 캐시 1:N** — 순간 × 팀 × 언어 × 팬 수준 조합으로 서버 1회 생성 후 배포 | 경기당 고정 |
| 1:1 대화·Ask 직접 입력 | 서버 LLM 호출 (로그인 필수) | 대화량 비례 — 유료층 원가 |

- 무료층은 세그먼트 캐시로 애착을 만들고, 현금화는 자산형(카드 장식·유료 장식) — digital-items 원가 2분법과 일치
- 클라이언트에 API Key 보관 금지 (프로토타입 구조 폐기)
- 온디바이스 모델의 확장 내 가용성·지원 범위는 [H] — 구현 착수 전 확인
