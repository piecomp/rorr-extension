# 10. 법률 사전 검토 — 경기 이벤트 퀴즈 스트릭·Spark 상금

- 작성일: 2026-10-15 · 방법: 법률 컴플라이언스 체크(legal:compliance-check) + 법령 원문 조회(국가법령정보) + 공개 자료
- **법률 자문이 아님.** 출시 전 변호사 확인 필수. 판례·유권해석은 자동 조회에서 **검색되지 않음**(아래 §6) — 결론은 원문 조문 해석 수준
- 대상 기능: F-20 이벤트 퀴즈 스트릭, F-21 주간 퀴즈 순위·상금 (`02-feature-spec.md`)

---

## 1. 요약 판정

**조건부 진행 가능 (Proceed with conditions)**

- 설계상 핵심 방어선은 3가지이며, 셋 중 하나라도 깨지면 판정이 뒤집힘
  1. **참여 대가 없음** — Energy·Spark·유료 기능 결제를 참여 조건으로 걸지 않음
  2. **상금의 재산적 가치 최소화** — Spark는 구매·환불·양도·현금화 불가, Boost에만 사용
  3. **베팅 구조 없음** — 재화를 걸고 맞히면 배당받는 구조 금지
- 최대 리스크는 법률보다 **Riot 정책**(베팅·도박 기능 금지 조항)의 해석과 **미성년자** 처리

> **업데이트 2026-10-15**: 사업 담당 전달 의견 — "현금화하지 않으면 재산상 이익으로 보지 않는다." 이에 따라 정책 §5-6 반영. 이 판단은 현금화·외부 거래 차단이 유지되는 동안만 유효하며, 의견의 출처·근거(변호사 서면 여부)는 기록으로 보관할 것. Riot 정책 확인(G-12)과 공식 규칙 게시는 여전히 필수

## 2. 적용 법령·정책

| 법령·정책 | 관련성 | 핵심 요건 | 본 기능 해당 여부 [검토 의견] |

| 같은 법 시행령 제1조의2 (추첨업·경품업) | 한국 | 증표 제공 후 추첨·등수로 당첨금 교부하는 **영업** | 무상·비추첨(순위)·현금성 없는 상금 → 해당 가능성 낮음 [H] |

| 미국 — 비금전적 대가 | 영문권 | "상당한 시간·노력의 지출"도 대가로 볼 수 있다는 실무 견해 | 경기 시청·로그인 요구가 대가로 해석될 여지 낮으나, **설치·로그인 없이도 참여 가능한 무료 대체 경로** 검토 [H] |

| 소득세법 제21조 (기타소득) | 한국 | 경품 등 기타소득 과세 | Spark는 현금 가치 없음 → 과세 소득 해당 가능성 낮음 [세무 확인] |

## 3. 요구사항 점검

| # | 요구사항 | 상태 | 조치 |
|---|---|---|---|
| 1 | 참여에 어떤 대가도 요구하지 않음 | 설계 반영 | 퀴즈 응답은 비로그인도 가능, 재화 차감 0 (F-20 AC) |
| 2 | 재화를 걸고 배당받는 구조 없음 | 설계 반영 | "재화를 거는 예측" 범위 밖 명시 (`02` 범위 밖) |
| 3 | 상금의 현금성 차단 | 설계 반영 | Spark: 구매·환불·양도·현금화 불가 (정책 §1) |
| 4 | 공식 규칙(Official Rules) 게시 | **미충족** | 기간·자격(연령·거주지)·참여 방법·1인 1계정·순위 산정·상금 내용과 가치·지급·제외 지역·주최자 명칭과 주소 포함 |
| 5 | 순위 산정의 공정·투명 | 설계 반영(부분) | 서버 시각 마감·결과 공개 전 마감·무효 처리·점수 산식 공개 — 산식은 규칙 페이지에 게시 |
| 6 | 미성년자 처리 | **미충족** | 상금 수령 연령 정책 결정 (§5 권고) |
| 7 | Riot 포털 등록·기능 고지 | **미확인** | 퀴즈·상금 기능을 포함해 등록 상태 확인, 서면 문의 |
| 8 | 개인정보 고지 | 미충족 | 순위 공개·부정 탐지 처리 목적을 처리방침에 추가 |
| 9 | 규칙 변경 금지 | 미설계 | 주간 회차 시작 후 규칙·상금 변경 불가 (공식 규칙 원칙) |
| 10 | 제외 지역 지정 | 미설계 | 법률 확인 전 미확인 국가는 상금 지급 대상에서 제외 가능하도록 서버 설정 |

## 4. 리스크

| 리스크 | 심각도 | 완화 |
|---|---|---|
| Riot이 "예측 + 상금"을 베팅 유사 기능으로 판단 | **상** | 출시 전 개발자 포털 문의, 판단 전까지 상금 기능은 서버 플래그로 OFF 가능하게 설계. 퀴즈 자체(상금 없음)는 별도 운영 가능 |
| Spark에 사실상 가치가 생김(외부 거래·계정 거래) | 중 | 양도 불가·계정 거래 금지 약관, 이상 거래 탐지 |
| 향후 현금·실물·스폰서 상금으로 확대 시 성격 변화 | 상 | 확대 시 별도 법률 검토 게이트 — 미국 등록·보증금, 한국 경품 판단 재검토 |
| 미성년자 상금 수령·순위 노출 | 중 | §5 권고 적용 |
| 지연이 짧은 중계 시청자 우위 → "공정성" 분쟁 | 중 | 결과 공개 전 마감, 무효 처리, 규칙에 명시 (OI-27) |
| "게임물" 분류 → 등급분류 등 별도 의무 | 중 | 퀴즈를 독립 게임이 아닌 시청 보조 기능으로 설계, 변호사 판단 |

## 5. 권고 조치 (우선순위)

1. **Riot 개발자 포털 문의** — 퀴즈·순위·Spark 상금 구조를 그대로 설명하고 "betting or gambling functionality" 비해당 확인 (게이트 G-12)
2. **공식 규칙 페이지 작성** — 영문 기준, 웹(rorr.club)에 게시하고 익스텐션 Ranking 탭에서 링크
3. **미성년자 정책** [권고]: 퀴즈 참여는 전 연령 허용, **상금 수령은 만 14세 이상(한국)·13세 이상(미국 COPPA)으로 제한**하고 미만은 순위 표시만, 미성년 순위 노출은 기본 OFF 유지(정책 §5)
4. **상금 성격 고정** — Spark 외 현금·상품권·실물·스폰서 상금 도입 시 별도 검토 게이트 신설
5. **변호사 검토 의뢰 항목**: 사행특례법 "재산상 이익" 해석, 게임산업법 제28조 제3호 적용 여부, EU 대상 국가 경품 규정

## 6. 조회 결과와 한계

- 확인된 원문: 사행행위 등 규제 및 처벌 특례법 제2조, 같은 법 시행령 제1조의2·제8조(미성년자 참여 금지는 허가 영업 대상 규정), 게임산업진흥에 관한 법률 제2조·제28조, Riot LoL 개발자 정책 Monetization 조항
- **조회 실패**: 위 쟁점에 대한 판례·법제처 해석례 — 자동 검색에서 0건. 존재하지 않는다는 뜻은 아님
- 미조사: EU 회원국별 경품 규정, 크롬 웹스토어 원문 대조
