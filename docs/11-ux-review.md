# 11. UX·UI 리뷰 — 수석 디자이너 관점 (시청 맥락 기준)

- 작성일: 2026-10-15 · 대상: Design 캔버스 "RORR Extension v2.0 시안" (380×952 실측 기준)
- 전제: 브라우저 왼쪽에 중계, 오른쪽 사이드 패널에 익스텐션. **시선의 80% 이상은 중계에 있다** — 패널은 "곁눈으로 보는 화면"

## 1. 핵심 진단

| # | 문제 (v1 시안) | 왜 문제인가 | 개선 (03-B 시안에 반영) |
|---|---|---|---|
| 1 | 퀴즈·Boost가 패널 **하단**(드로어 위)에 있음 | 중계 영상은 화면 상단~중단(약 y 80–680)에 있다. 하단은 시선 이동이 가장 길다 | 시간 민감 요소(스코어·퀴즈·Boost)를 **영상과 같은 높이(상단~중단)**로 올리고, 채팅·반응 칩은 하단으로 |
| 2 | 캐릭터가 전체 배경 → 오버레이 카드가 캐릭터를 가림 | 감정 표현(얼굴)과 정보가 서로 가린다 | 경기 중에는 캐릭터를 **상반신 크롭 스테이지**로 축소, 평시(대화)에만 전신 |
| 3 | 퀴즈 답 버튼이 팀 고정 배치 | 중계 스코어보드는 **블루 사이드=왼쪽, 레드 사이드=오른쪽**. 순서가 다르면 오답 클릭 유발 | 버튼·스트립 좌우를 **중계 진영 배치와 일치**, "BLUE SIDE / RED SIDE" 라벨 병기 |
| 4 | 말풍선이 2~3줄 | 곁눈으로 읽을 수 없다 | 경기 중 대사는 **1줄(약 40자)** 상한, 상세는 접힘 |
| 5 | 마우스 이동 필수 | 중계를 보며 오른쪽까지 커서 이동은 순간을 놓친다 | **단축키**: 1/2 = 퀴즈 답, B = Boost 시트, Esc = 닫기 (`chrome.commands`, 패널 포커스 시) — 버튼에 키 표시 |
| 6 | 칩 높이 36px | 터치·정밀 클릭 기준 미달 | 모든 조작 요소 **44px 이상** |
| 7 | 마감 카운트다운 소형 텍스트 | 남은 시간이 판단의 핵심 | 퀴즈 카드 우상단 **고대비 타이머 배지** |

## 2. 접근성 기준 (출시 수용 기준에 추가)

- **명도 대비**: 본문 4.5:1 이상, 캐릭터 이미지 위 텍스트는 반투명 금지 → 불투명 배경 카드 사용
- **색만으로 구분 금지**: 팀은 색 + 진영 라벨 + 위치 3중 구분 (적록 색각 고려 — 블루/레드는 명도 차이도 확보)
- **움직임**: 환호 파티클·화면 흔들림은 `prefers-reduced-motion` 시 끔. 초당 3회 이상 번쩍임 금지(WCAG 2.3.1)
- **스크린 리더**: 퀴즈 열림/마감·큰 순간 예고는 `aria-live="polite"` 1회 안내, 초 단위 카운트다운은 읽지 않음
- **시간 제한**: 실시간 경기라 연장 불가(WCAG 2.2.1 실시간 예외) → 대신 마감 10초 전 시각·청각 신호(선택)
- **소리**: 큰 순간 예고에 선택형 짧은 효과음 — 시선이 중계에 있어도 인지. 기본 OFF, 첫 경기에서 켜기 제안
- **패널 폭 가변**: 크롬 사이드 패널은 사용자가 폭 조절 → 320px에서 깨지지 않고, 480px 이상이면 캐릭터 스테이지 확대
- **전체 화면 시청**: 중계를 전체 화면으로 보면 패널이 가려짐 → 첫 실행에서 "극장 모드/창 전체 화면 권장" 1회 안내

## 5. 확인 필요

- **캐릭터 이름**: 실제 빌드는 "Seoha", 브랜드 문서는 컴패니언 이름이 "Muse" — Muse = 서비스 속 컴패니언 역할, Seoha = 캐릭터(페르소나) 이름으로 볼지 결정 필요
- 비파트너 선수 닉네임(예: 비교 화면의 상대 선수)을 **통계 화면**에서 쓰는 범위 — 정책 §2는 Boost·카드 맥락 금지, 웹 통계에는 노출 중. 정책에 통계 화면 예외를 명시할지

## 6. 목업 v2 반영 (2026-10-15)

목업: `mockup/index.html` (Claude 아티팩트 v2와 동일)

### 6-1. 경기 중 하단 영역 축소

- 문제: 하단 고정 영역 약 178px(Boost 버튼 52 + 반응 칩 줄 52 + 입력창 64 + 간격) — 380×952 패널 높이의 약 20%
- 조치: **하단 독 1줄(68px)** 로 통합 — 질문 입력(좌, 가변 폭) + ⚡ Boost(우, 고정 폭)
  - Boost는 스크롤 영역에서 독으로 이동 → 큰 순간 예고 시 골드 링·카운트다운(0:40) 표시, 단축키 B 유지
  - 반응 칩(Cheer!/Ugh…/Let's go)은 캐릭터 스테이지 좌상단 오버레이로 이동 — 캐릭터에게 반응하는 맥락과 일치
  - 확보한 높이는 스테이지 확대(230 → 276px)와 여백(카드 간격 10 → 12, 좌우 12 → 14)에 사용
- 순간 기록 행을 누르면 관련 선수 보기로 이동(예: Baron 교전 → Faker)
