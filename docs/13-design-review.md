## 2. 유지한 것(브랜드·정책)

- 팀 좌/우 색(#2F9CFC/#FE2054), Energy #00B395, Companion BG #1D2333 — 웹과 동일 토큰
- 라운드 체계: 컨테이너 16·14px, 행 12px, 인터랙티브는 필 — 규칙 일관
- 비제휴 고지·Energy 환불 불가 문구·Official rules 링크 등 정책 문구는 의미 변경 없이 구두점만 정리

## 3. 목업 범위 밖 — 실제 빌드에서 처리

- 폰트: 아티팩트 CSP 제약으로 Noto Sans KR 대체 표시 중. 빌드는 Pretendard Variable 번들
- 아이콘: 목업은 인라인 SVG. 빌드는 단일 아이콘 라이브러리(Phosphor 등)로 통일, 스트로크 1.8 고정
- 로딩·빈·오류 상태: 팀/선수 스켈레톤, 응원 0건 빈 상태 일부만 있음 → 컴포넌트 명세에 포함 필요
- 대비 검증: 11px 보조 텍스트(--faint on --panel ≈ 5.0:1) 통과, 실제 빌드에서 자동 검사 권장

## 4. v5 — 라이브 화면 미니멀화 (2026-10-16)

- 문제: 라이브 중 고정 UI(스코어 카드·스테이지 박스·반응 칩·모먼트 바·독)가 아바타 하반신·얼굴 주변을 가림
- 원칙: 아바타가 화면 전체 배경, 상시 UI는 2개(상단 스코어 필·하단 독)만, 나머지는 필요할 때만 등장

| 요소 | v4 | v5 |
|---|---|---|
| 아바타 | 박스 안 상반신 | 패널 전체 풀블리드 배경, 팀 컬러 오라 |
| 스코어 | 78px 카드(진영 라벨·골드 텍스트) | 44px 유리 필 1줄(팀·킬·시각 + 골드 미니바). 누르면 상세(게임·골드·팀 페이지·퀴즈 스트릭) |
| 큰 순간 예고 | 별도 배너 + 독 카운트다운 | 스코어 필 아래 골드 필 1개, Boost 버튼은 골드 링만 |
| 서하 대사 | 스테이지 하단 상시 말풍선 | 7초 후 자동 페이드, 퀴즈 중에는 숨김(퀴즈가 곧 서하의 질문) |
| 퀴즈 | 대기 중 카드 상시 | 문제가 열릴 때만 하단 유리 카드, 결과 6초 후 접힘 |
| 반응 칩 | 스테이지 좌상단 상시 3개 | 독의 반응 아이콘 → 팝오버 |
| 모먼트 | 48px 한 줄 바 | 독의 카드 아이콘 + 개수 배지 → 팝오버, 새 모먼트는 토스트 1회 |
| 스트릭·감정 라벨 | 우상단 필 2개 | 스트릭은 스코어 상세로 이동, 감정 라벨 제거(표정이 대신) |
| 독 | 입력창 + Boost | 유리 필 1줄: 모먼트 · 반응 · 입력 · Boost (터치 영역 44px) |

- 상시 UI 높이: 약 290px(스트립 78 + 반응 칩 줄 + 퀴즈 대기 카드 + 모먼트 바 + 독) → 약 110px(스코어 필 44 + 독 56 + 여백)
- 투명도 감소 설정(`prefers-reduced-transparency`) 시 유리 효과 대신 불투명 배경
- 근거: ui-ux-pro-max 우선순위 규칙(콘텐츠 우선·점진 공개·44px 터치·의미 있는 모션). 스킬 검색 DB는 동기화본에 없어 기본 규칙만 적용
