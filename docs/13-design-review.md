## 6. v9 — 모먼트 카드 시각화 (2026-10-16)

- 문제: '지금까지의 모먼트'가 텍스트 행 목록이었고, 행을 누르면 바로 선수 페이지로 이동. 웹은 카드로 보여 줘서 모먼트를 '소장품'으로 인식시키는데, 익스텐션에서는 그 가치가 드러나지 않음
- 원칙: 웹 모먼트 카드(`.bx-card`)와 같은 시각 언어 — 등급 테두리(실버·골드·홀로그램), 재화 단계 칩, T1 파트너 에디션, 일련번호 + 거래·양도 불가

| 위치 | 변경 |
|---|---|
| 독의 모먼트 팝오버 | 텍스트 목록 → '오늘의 모먼트' 가로 카드 스트립(미니 카드 128×190). 카드 없는 순간(퀴즈만 맞힌 순간)은 점선 고스트 카드 "+30 · 카드 없음. 순간에 Boost하면 카드가 발급돼요" |
| 카드 상세 | 미니 카드를 누르면 풀 카드(252px) 오버레이. 포인터를 따라 기울기·광택 효과(동작 줄이기 설정 시 비활성). 하단 '선수 페이지' · '계속 보기' |

| 리캡 | '오늘 받은 카드' 썸네일 줄 추가(누르면 상세) |

### 6-1. v10 — 카드 뒷면 (2026-10-16)

- 풀 카드(상세·발급 화면)를 누르면 뒤집힘. 키보드 Enter/Space 동작, 동작 줄이기 설정 시 애니메이션 없이 전환
- 뒷면 구성(웹 `backHTML`과 동일 구조): '그 순간' + 일련번호, 한 줄 설명("2세트 18:20, 승리확률이 58%에서 83%로 25%p 움직인 순간이에요."), 순간 전후 승리확률 꺾은선(등급 색), 함께 Boost 인원 · 내 Boost 시각, 파트너 에디션 발급 문구(협약 기간 중 제작), '그 순간 다시 보기' · '자랑하기'
- '그 순간 다시 보기'는 방송 다시보기 해당 시점 연결, '자랑하기'는 공유용 카드 이미지 생성 — 실제 빌드에서 플랫폼별 다시보기 URL·이미지 생성 방식 확정 필요
