- 대상: Boost 시트(익스텐션 380px 패널 하단 시트), 팀 보기 '지금 이 순간' 카드, 모먼트 카드 발급 연출

## 4. 현지화 메모

- 'Boost', 'Energy', 'Spark'는 고유 명사로 번역하지 않음
- 한국어 수량 표기는 숫자에 '명'을 붙여 씀(2,418명). 영어 'left'는 '남음'
- 한국어 문자열이 영어보다 길어지는 구간(결제 수단 타일·CTA) 380px 기준 1줄 확인 완료
- 법무 확인 필요: 'Non-refundable' 1줄 요약이 전자상거래법상 청약철회 제한 고지로 충분한지(결제 화면은 웹, 익스텐션은 사용 화면이므로 요약 + 전문 링크 구조 제안)

- 대안: A '제휴 소식 받기'(짧음, 블록 제목과 함께 쓸 때) / B 'GEN이 합류하면 알려줘요'(친근, 서하 말투와 맞출 때)

## 부록. Boost 배분 비율 표기 (2026-10-16, 목업 v17)
- 문제: 상시 노출 문구 '환불 불가 · 70%는 T1에 전달'이 T1 조건을 표준처럼 보이게 함. 팀별 약정이 달라질 경우 비교·혼선 발생
- 원칙: 상시 노출은 팀과 무관한 공통 문구, 정확한 비율은 ⓘ 상세에서 '팀별 약정 값'으로 표기

| 위치 | 변경 전 | 변경 후 |
|---|---|---|
| 상시 문구 | 환불 불가 · 70%는 T1에 전달 | 환불 불가 · 일부는 T1에 전달 |
| ⓘ 상세 | 70%는 T1에, 30%는 RORR에 배분되며 RORR이 결제 수수료를 부담합니다. | 사용한 Energy의 일부는 T1과의 파트너 약정에 따라 T1에 배분됩니다(현재 70%). 배분 비율은 팀마다 다를 수 있으며, 결제 수수료는 RORR이 부담합니다. |

- RORR 몫(30%) 직접 표기 삭제 — 팀 몫만 표기하면 나머지는 자명, 팀별로 다를 때 'RORR이 더 가져간다' 비교 프레임 방지
- 대안: A '환불 불가 · T1 파트너 응원'(비율 언급 없음, 더 부드러움) / B '환불 불가 · 팀 배분 안내 ⓘ'(정보 위치만 안내)
- 확인 필요(법무): 팀에 '전달'된다고 표시하는 경우 비율을 결제·사용 전 어느 수준으로 고지해야 하는지(표시광고법·전자상거래법). 현재안은 ⓘ 한 번 탭으로 확인 가능
- 현지화: 영문 'Part goes to T1' / 'currently 70%' — 'currently'로 약정 변경 가능성 표시, 팀명·비율은 변수 처리

## 부록. T1 서포터 순위 하단 고지 삭제 (2026-10-16, 목업 v18)

## 부록. v19 카피·연동·연출 정리 (2026-10-16)
### 1. 오늘의 모먼트 — 퀴즈 기록 카드
- 문제: '카드 없음. 순간에 Boost하면 카드가 발급돼요'는 결과(정답/오답)와 카드 규칙이 한 문장에 섞여 맥락 파악 어려움
- 변경: 결과 1줄 + 규칙 1줄로 분리
  - 정답: '정답 · +30점' / 오답: '이번엔 빗나갔어요'
  - 공통: '카드는 Boost한 순간에만 발급돼요.'
- 대안: '퀴즈 기록 · 카드 없음'(정보형) / '다음 순간에 Boost하면 카드를 받아요'(행동 유도형 — 오답 직후 판매 압박으로 읽힐 위험)
### 2. 파트너 배분율 비노출
- ⓘ 상세의 '(현재 70%)' 삭제 → '사용한 Energy의 일부는 T1과의 파트너 약정에 따라 T1에 배분되며, 결제 수수료는 RORR이 부담합니다.'
- 근거: 파트너 측 비공개 선호 가능성, 팀별 조건 비교 방지
- 확인 필요(법무): 비율 미표기 시 '팀에 전달' 표시의 고지 충분성. 웹사이트 FAQ의 70% 표기도 동일 기준으로 정리 필요
### 3. 충전 연동
- Energy 충전 → https://piecomp.github.io/rorr-hero/#account/energy, Spark 받기 → https://piecomp.github.io/rorr-hero/#spark (새 탭)
- 적용 위치: Boost 시트 하단 링크, 메뉴 'ON RORR.CLUB' 항목(외부 이동 ↗ 표시)
### 4. 카드 등장 연출
- 변경 전: 배경과 카드가 함께 확대(scale .85 → 1)
- 변경 후: 배경은 흐림(blur 12px)·어둡게만 전환, 카드는 0.12초 뒤 아래에서 떠오르며 등장(이동 36px·기울기 14°→0), 'NEW CARD'·버튼은 순차 등장
- 동작 줄이기 설정 시 모든 애니메이션 정지
### 5. 점수 상세(GEN)의 '서하에게 묻기' 삭제
- 판단: 불필요 — 바로 아래 입력창과 팀 페이지 '더 물어보기'로 중복, 칩 상세의 목적(팀 정보 확인·이동)과 무관
- 대체: 'GEN 팀 페이지' + '파트너 준비 중' 표기(T1 쪽 '팀 페이지 + 연속 정답'과 구성 대칭)
### 기타 수정
- 입력창 확장 조건을 '입력창 포커스'로 한정 — 기존에는 모먼트 버튼을 누르는 순간 버튼이 사라져 동작하지 않던 결함 수정
