## 3. 사용자 검증 질문 (후속)
- 확장 → 웹 충전 → 확장 복귀 후 Boost 완료율 (v38에서 복귀 경로 추가 — 아래 §4)
- 설치 동기: 퀴즈 스트릭 vs 시청 경험
- 웹 '선수 응원' vs 확장 '순간 응원 + 내 선수 주인공' 차이 인지 여부
- 방법: 사용성 테스트 6명, '큰 순간 Boost → Energy 부족 → 충전 → 재Boost' 과제의 완료율·이탈 지점
