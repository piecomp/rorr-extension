### MK-1. Energy 유료/보너스 구분 표시 🟡
- 근거: 정책 v1.3 §1 UI 규칙(Boost는 유료 Energy만 사용) · 웹 handoff 18 #14(`insufficient_paid_energy`)
- 현재
  - 메뉴 프로필(1059줄): `⚡ 120 Energy` 합계만 표시
  - Boost 시트 재화 선택(1087줄): 잔액 `120` 합계만 표시
  - 안내 문구(1382줄)는 "유료 Energy만 사용"으로 이미 반영
- 요구
  - 메뉴: 합계 옆에 `유료 100 · 보너스 20` 보조 줄(예시 값, 웹과 동일 값 사용)
  - Boost 시트 Energy 선택지: 사용 가능 잔액 = **유료 잔액**으로 표시
  - 유료 잔액이 단계 금액보다 적으면 Energy 선택지 비활성 + `insufficient_paid_energy` 문구 + "Energy 충전 ↗"(웹 `#account/energy`)
- 완료 기준
  - 보너스 Energy가 Boost 가능 금액으로 보이는 화면 0곳
  - 테스트 상태 1개 추가(유료 0 · 보너스 20)로 비활성 화면 확인 가능

### MK-3. 퀴즈 문항 무효 상태 🟡
- 근거: 정책 §5-6 — 마감 전에 이벤트가 발생하면 문항 무효(전원 미응답 처리), 미응답은 스트릭 유지
- 현재: 퀴즈 상태는 `idle → open → locked → done`(1118·1320~1328줄)뿐, 무효 화면 없음
- 요구
  - 상태 `void` 추가(마감 전 이벤트 발생 또는 순간 `cancelled`)
  - 문구 예: "이번 문항은 마감 전에 결과가 나와서 무효가 됐어요. 스트릭은 그대로예요."
  - 선택한 답 표시 해제, 점수·스트릭 변화 없음
- 완료 기준: 퀴즈 단계에서 무효 상태 재현 가능, 스트릭 숫자 유지 확인
