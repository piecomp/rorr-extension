## 2. 확정·논의 중 구분

| 표시 | 의미 | 개발 처리 |
|---|---|---|
| (표시 없음) | 확정 | 그대로 구현 |
| **[논의 중]** | 정책·법률·협약 확인 전 | 기능 플래그 뒤에 구현, 기본 꺼짐(출시 빌드) |

## 3. 옮기지 않을 것

- 샘플 데이터·시뮬레이션: 경기 시계, 점수·골드 변화, 퀴즈 출제, 큰 순간 발생, 팬 수, 순위 표, 선수 수치 → 실시간 API
- 데모 상태: 잔액(`eBal 120 · sBal 35`), 카드 목록, 포인트, 내 선수, 행운 박스 결과(`?box=`) → 서버 상태(웹과 같은 계정)
- KO 번역 방식: `const KO={영문: 국문}` + 화면 텍스트 치환 + 정규식 59개 → i18n 키 체계로 재작성. `i18n-ko.json`은 **문구 원본**으로만 사용
- 시연 조작 영역 전체(단계 버튼, 전체 흐름 재생, 배경 선택, 화면 바로가기, 언어 버튼, 스폰서 미리보기)
- 바깥 크롬 프레임·중계 자리 표시(`.side` 바깥) — 실제는 크롬 Side Panel API 영역(폭 가변, 최소 320px)

## 4. 문구 원칙 (위반 시 출시 차단)

| 금지 | 대신 | 근거 |
|---|---|---|
| "당신의 Energy가 T1에 전달돼요", "팀에게 보내기", "응원금", "송금", "후원금" | "RORR는 Boost 수익의 일부를 파트너 팀과 나눠요", "파트너 수익 배분" | 정책 §2-1 |
| 배분 비율(70:30 등) 화면 표기 | 비율 미표기, ⓘ 펼침에서도 비율 없음 | 정책 v1.3 §8(대외 비공개) |
| "선수에게 Boost", "선수에게 보내기", "선수에게 전달됩니다" | "카드 주인공", "내 선수의 순간" | 정책 §2-1·§4-2 |
| "미계약", "파트너 준비 중", "Partner pending" | "비제휴 팀" / "Not a partner team" | 정책 §0 |
| "한정판", "레어", "한정 수량" | "판매·거래 불가", 시즌 표기 | 정책 §4-2 |

- 후원 표시는 항상 '후원/Sponsored' 배지 포함. 카드 앞·뒷면에는 브랜드 금지(§6-1)
- 환불 고지 위치: Boost 창 차감 줄 + ⓘ(정책 §1-2). 배분 문구로 대체 금지(13 §10 사고 이력)
- 한국어 조사: 이름 뒤 '이/가', '은/는'은 받침 판별(예: Doran이·Faker가) — `05-state-logic` §9

## 5. 접근성 기준 (출시 최소)

- 터치 영역 44×44px 이상(시각 크기가 작으면 의사 요소로 확장 — `.hsp-open::after`, `.bh-i::after` 방식)
- 글자 12px 이상(11px 이하 사용 금지 — v43에서 정리). 목업 v45 잔여 2곳은 구현 시 12px로: 메뉴 내 선수 이름(`.menu-panel #mFav .bh-p span` 11px)·미니 모먼트 카드 보조(`.mc.mini .nm em` 10px). 글자가 아닌 기호(ⓘ의 i, 스폰서 로고 글자)는 예외
- 명도 대비 본문 4.5:1 이상. 영상·캐릭터 위 오버레이는 배경 불투명도 0.85 이상(`--overlay-strong`)
- 모든 아이콘 단독 버튼에 접근 가능한 이름(현재 목업 기준 이름 목록은 04-components §5)
- `prefers-reduced-motion`: 입자·흔들림·회전·박동 생략, 의미 있는 정보(타이머 테두리)는 유지
- 상태 변화 알림: 토스트 `role="status"`, 퀴즈 `aria-live="polite"`, 행운 박스 결과 `aria-live="assertive"`
