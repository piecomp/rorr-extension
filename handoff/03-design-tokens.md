## 2. 글자

| 토큰 | 크기 | 사용처 |
|---|---|---|
| `--fs-12` | 12px | 라벨·보조·고지·확률(최소 크기) |
| `--fs-13` | 13px | 칩 안 문구, 카드 주인공 줄, 행운 박스 버튼 |
| `--fs-14` | 14px | 본문 기본 |
| `--fs-16` | 16px | Boost 주 버튼 |
| `--fs-20` | 20px | 시트 제목 |
| `--fs-24`·`--fs-28` | 24·28px | 숫자 강조(순위·포인트) |

- 글꼴 `--f-ui`(Pretendard Variable). 숫자는 `font-variant-numeric: tabular-nums`(스코어·시간·잔액)
- 줄 높이 본문 1.5, 칩·버튼 1
