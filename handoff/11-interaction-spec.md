# 11. 인터랙션 정의

- 작성일: 2026-10-17 · 기준: 목업 v45 실측(`@keyframes`·`transition` 원문) · 토큰: 03-design-tokens §3 모션
- 열: 요소 · 트리거 · 반응 · 시간/곡선 · 키보드·보조기술 · 측정 이벤트(14-analytics-events)
- 값 출처: `keyframe 이름`이 함께 적힌 값은 목업 원문, 이름 없는 값(토스트 2.4초·카드 뒤집기 .5초·시트 끌어 닫기 등)은 **이 문서가 정한 구현 기준**
- 데스크톱 크롬 사이드 패널 기준 → 마우스·키보드가 주 입력. 호버는 보조 신호일 뿐 정보 전달에 쓰지 않음

## 1. 공통 규칙

| 항목 | 규칙 |
|---|---|
| 누름 반응 | 모든 버튼 `:active` 축소 `scale(.98)` 140ms `cubic-bezier(.23,1,.32,1)` · 호버 밝기 +6%(`--send-h`, `--energy-h`). **hover는 `@media (hover:hover) and (pointer:fine)` 안에서만**(터치 기기에서 눌린 상태가 남지 않게) |
| 포커스 | `:focus-visible` 2px 윤곽 `--selected`, 바깥 간격 2px. 마우스 클릭에는 표시하지 않음 |
| 비활성 | 불투명도 .4 + `aria-disabled="true"` + 커서 기본. 이유가 있으면 바로 아래 한 줄 설명 |
| 진입·퇴장(v47 확정) | 진입 = ease-out 계열 곡선, 퇴장 = 진입보다 짧게(150~200ms). 닫는 중 다시 열면 퇴장 취소. `hidden` 즉시 전환 금지(아래 표) |
| 동작 줄이기(v47 확정) | `prefers-reduced-motion: reduce` → 입자·흔들림·회전·박동·화면 쓸기·위치 이동 없음. **투명도·색 전환은 150ms로 유지**, 시트·메뉴·알림·목록·토스트·화면 전환·카드 공개는 150ms 페이드, 퇴장은 투명도 120ms. **5초 확인 링·카운트다운 숫자는 유지**(정보) |
| 화면 전환 | `.view` 진입 `viewin` 0.22초 `cubic-bezier(.16,1,.3,1)` — 아래에서 8px·투명 → 제자리 |
| 시트 | 진입 `translateY(100%)→0` 260ms `cubic-bezier(.32,.72,0,1)`(드로어 곡선) + 막 투명도 200ms ease-out · 퇴장 200ms. **키보드 `B`로 열 때는 애니메이션 없음**. 닫기: 막 클릭 · `Esc` · 아래로 끌기 80px 이상 |
| 토스트 | 상단(HUD 아래, top 62px) 고정. 진입 `translateY(-100%)`+투명 → 제자리 200ms `cubic-bezier(.23,1,.32,1)` · 2.45초 유지 · 퇴장 150ms(위로 8px+투명) · `role="status"`. 동시에 1개(새 토스트가 이전 것 교체) |
| 메뉴 | 진입 `translateX(100%)→0` 240ms 드로어 곡선 · 퇴장 180ms |
| 큰 순간 알림·채널 목록 | 진입 위에서 8px+투명 → 제자리 220ms(목록 180ms) `cubic-bezier(.23,1,.32,1)` · 퇴장 160ms. 큰 순간 알림은 카운트다운 0에서 퇴장 |
| 카드 공개 닫기 | 투명+`scale(.97)` 180ms |
| 서하 말풍선 문구 교체 | 보이는 중 문구가 바뀌면 150ms `blur(2px)`·투명도 .6 → 선명 교차(두 문장 겹침 방지) |
